- 사이트: https://serendipity-awates.github.io/study/
- 기록은 각 기기 브라우저에 저장됩니다.
- 처음 한 번 GitHub 토큰(gist 권한)과 비밀번호를 설정하면, 기록이 비공개 Gist로 기기 간 동기화됩니다. 다른 기기에서는 비밀번호만 넣으면 로그인됩니다.
